GitHub Pages
1. Upload every file in this folder to the root of a GitHub repository.
2. In repository Settings → Pages, publish from the branch containing these files.
3. Open the published page once while online before relying on offline mode.

Phone backup
- Keep index.html in the Files app for a basic offline copy.
- The installable version requires the full folder to be hosted over HTTPS (GitHub Pages works).
- Map buttons need a data connection or previously downloaded maps.

The service worker uses relative paths, so the PWA also works from a GitHub Pages project subdirectory.
